# Future Lens: AI Transition Simulator

Explore how work, learning, creativity, sports, investing, and everyday life evolved from **1980 to today** — and how AI may reshape them through **2050**.

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy on Streamlit Cloud

1. Push this repo to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. Connect **Coakley11/future-lens-ai-transition-simulator**.
4. Set main file: `streamlit_app.py`
5. Deploy.
